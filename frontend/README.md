# AI Sana — платформа задач и мультиплеерный 3D-кампус

Бизнес превращает короткое описание проблемы в карточку задачи: ИИ задаёт уточняющие вопросы, готовность считается по прозрачной формуле 0–100. Студенческие команды ходят по живому 3D-кампусу, видят друг друга онлайн, находят задачи-здания и откликаются. Бизнес вручную выбирает команду и подтверждает результат. Подтверждённый результат запускает для всех онлайн событие **GRAND TRIUMPH**.

Стек: React 19 + TypeScript + Vite 8 + three 0.186 + React Three Fiber 9 + drei 10. Сервер: Express 5 + Socket.IO 4 + SQLite (`node:sqlite`). Проверено на Node 22.23 и Node 24.3.

## Запуск
```bash
cd frontend
npm install
cp .env.example .env   # заполнить при необходимости; .env не коммитится
npm run dev            # сервер :3001 + фронтенд :5173 (прокси /api и /socket.io)
```
Открыть http://localhost:5173.

| Команда | Что делает |
| --- | --- |
| `npm run dev` | сервер (tsx watch) и Vite вместе |
| `npm run server` / `npm run dev:web` | по отдельности |
| `npm run build` | проверка типов клиента и сервера + сборка `dist/` |
| `npm start` | сервер; отдаёт `dist/` (или `FRONTEND_DIST`), если сборка есть |
| `npm test` | формула, ИИ-контракт, сквозной сценарий, сервер REST+Socket.IO, планировка мира |
| `npm run bots` | демо-боты для показа в одиночку (помечены «демо») |
| `npm run assets` | копирует выбранные модели из `assets-raw/` в `public/models/` |

### Переменные окружения (`.env`)
`PORT`, `HOST`, `DATABASE_PATH`, `ALLOWED_ORIGINS`, `SESSION_TTL_HOURS`, `FRONTEND_DIST`, `OPENAI_API_KEY`, `OPENAI_MODEL`, `AI_MODE` (`auto` | `stub` | `openai`), `AI_TIMEOUT_MS`, `AI_MAX_OUTPUT_TOKENS`. Ключ OpenAI читается только на сервере и не отдаётся клиенту. `GIT_MODE`, `GITHUB_TOKEN`, `GIT_TIMEOUT_MS` этот сервер пока не использует.

### Демо-входы (каждая вкладка — своя роль)
- Участники команд (по 3 человека): `#/login?as=user-team-datanomads`, `…-datanomads-2`, `…-datanomads-3` (Бейбарыс, Аян, Дана) и аналогично для `bytecraft`, `pixelsteppe`, `qazml`, `tulpar`.
- Бизнес: `#/login?as=biz-damdi` (пустое кафе для живого создания задачи), `biz-zhol`, `biz-qarjy` и др.
- Гость: `#/login?as=guest`.

Откройте 2–3 вкладки под участниками одной команды: они видят друг друга в мире, эмоции 1–4 синхронизируются.

## Архитектура
- `src/shared/domain.ts` — все бизнес-правила (роли, владение, черновик и подтверждённая версия, ручной выбор, этап +10 ровно один раз). Их выполняет сервер.
- `server/index.ts` — REST API и Socket.IO: `data.changed`, присутствие в мире, `world.triumph`.
- `server/world.ts` — присутствие игроков. Сервер берёт имя, команду, цвет и облик из сессии. Клиент присылает только позицию, поворот и тип движения (12 Гц, только при изменении) и эмоции из белого списка. Сервер ограничивает скорость и частоту сообщений.
- `server/store.ts` — SQLite: состояние одним JSON-документом в транзакции, хэши сессий.
- `server/ai.ts` — вопросы ИИ. OpenAI с JSON-схемой, 2 попытки, при ошибке откат на локальные вопросы.
- `src/api/http.ts` — клиент (fetch + Socket.IO). `src/api/mock.ts` — та же логика в браузере, используется только в автотестах.

**Планировка** от центра наружу:
1. **Triumph Plaza**: арка «AI SANA» высотой около 22 м с символом, фонтаны, скульптуры, Зал достижений.
2. Кольцо до 8 «главных» павильонов: задачи с самой высокой готовностью.
3. Пешеходная площадь с зелёными островками, лавочками и фонарями.
4. Тротуар и кольцевая дорога с машинами. Дорога огибает площадь и не пересекает её.
5. Кварталы:
   - бизнес (север): кафе и магазины;
   - инновации (восток): лаборатории и логистика;
   - зелёный (запад): академии, клиники, пруд;
   - команды (юг): базы команд, вход, скейт-площадка.
6. Резервный ряд участков, живая изгородь.
7. Высокие здания и горы только на заднем плане.

**Места задач.** Каждая задача, кроме главных, получает участок из 32 фиксированных (плюс 18 резервных и внешнее кольцо). Участок выбирается по `seed = hash(task.id)` с учётом отрасли. Место одинаковое после перезагрузки и у всех игроков. Новая задача не сдвигает старые, а декор вокруг не переезжает.

Главные павильоны пересчитываются по рейтингу. Если задача войдёт в первую восьмёрку или выпадет из неё, она переедет между центром и своим участком.

**Готовность меняет оформление, а не размер здания:**
- **черновик:** леса и конусы, тусклый маяк;
- **рабочая:** вывеска, клумбы, реквизит;
- **готовая:** козырёк, кровельное оборудование, яркий маяк;
- **приоритетная:** флаги, ковровая дорожка, золотой акцент.

Уровень различается не только цветом: меняются высота маяка, число дуг кольца, значок и слово в маркере.

**Управление:**
- WASD или стрелки — ходить, Shift — быстрее;
- мышь — повернуть камеру, колесо — масштаб;
- `E` — открыть ближайшую задачу;
- `M` — карта;
- `1–4` — эмоции: помахать, ура, указать, праздновать;
- «Моя команда» — показать союзников на карте.

При первом входе за сессию камера делает облёт около 6,5 с. Любая клавиша его пропускает, при `prefers-reduced-motion` облёта нет.

**Эмоции и idle-действия** используют ближайшие клипы из Kenney Mini Characters: `interact-right`, `emote-yes`, `holding-right`, `jump`, `emote-no`, `holding-both`, `crouch`, `sit`. Отдельных анимаций «помахать» и «указать» в наборе нет.

**GRAND TRIUMPH.** Запускается, когда бизнес подтверждает результат этапа. В P1 у команды один этап на задачу, поэтому подтверждение этапа равно завершению задачи. Клиент вызвать триумф не может. Последовательность:
1. Здание задачи подсвечивается, маяк поднимается, появляется «ЗАДАЧА ЗАВЕРШЕНА».
2. Загорается монумент, по миру проходит световая волна.
3. Появляются конфетти и фейерверки (около 520 частиц), база команды празднует.
4. Над площадью и в HUD показывается объявление.

**Отладка:** `#/world?debug3d=1` показывает FPS, число вызовов отрисовки, треугольники, онлайн, частоту сети, позицию, район, выбранную задачу, активные события. Участки и коллайдеры подсвечиваются.

**Отказоустойчивость:**
- модель не загрузилась — вместо неё простая геометрия;
- аватар не загрузился — простая фигура цвета команды;
- нет WebGL — 2D-каталог;
- ошибка сцены — кнопка «Открыть 2D-каталог».

### Что не даёт баллов
Ходьба, эмоции, онлайн-время, отклики и отправка ссылки на коммит баллов не дают. Официальные показатели меняют только действия бизнеса, подтверждённые сервером. Готовность задачи и прогресс команды — разные величины.

## Модели (все CC0)
Лицензии перечислены в `public/models/LICENSES.txt`, исходные архивы лежат в `assets-raw/` (не в git).
- **Kenney City Kit (Commercial):** средние здания углов и дальний фон, навесы, зонтики.
- **Kenney Car Kit:** машины, конусы, коробки.
- **KayKit City Builder Bits:** лавочки, фонари, светофоры, кусты, гидранты.
- **Kenney Mini:**
  - Characters — игроки и NPC;
  - Forest — деревья и камни;
  - Market — витрины;
  - Arcade — автоматы;
  - Skate — скейт-площадка;
  - Arena — только кубок.

Здания задач и монумент собраны из примитивов: в наборах нет подходящих моделей с узлами `Core_Fill`, `Beacon`, `Ring_Approved` из ТЗ 5.5.

## Проверено и не проверено
- **Проверено 2026-09-23 (повторно, в браузере):**
  - `tsc` для клиента и сервера без ошибок;
  - `npm test` — 17/17;
  - `vite build`;
  - `npm run dev`: backend `http://127.0.0.1:3001`, frontend `http://localhost:5173`;
  - сцена в браузере рисуется (WebGL canvas, площадь, дороги, павильоны, базы команд, аватар);
  - WASD двигает локального игрока; камера облёта и карта `M` работают;
  - здания задач видны; карточка задачи открывается из «Все задачи» (сидед: Telegram-бот Жол Экспресс, 100/100);
  - карта мира показывает Triumph Plaza, участки и базы команд;
  - мультиплеер: две независимые сессии (`user-team-datanomads` и `…-datanomads-2`) — HUD «2 online», оба аватара в одном мире, движение второго видно первому;
  - GRAND TRIUMPH: бизнес `biz-qarjy` нажал «Подтвердить результат» на этапе задачи `task-fintech`; в мире появился баннер команды QazML;
  - `#/world?debug3d=1`: в этой сессии оверлей показал FPS 60, ~473 draw calls, ~992k треугольников, online 2.
- **Не проверено / не утверждается:**
  - стабильные 60 FPS на любом железе и «продакшен-производительность»;
  - визуально отчётливая синхронизация эмоции 1–4 на втором клиенте (клавиша 1 отправлена, поза на скрине не выделена);
  - живой вызов OpenAI с ключом из `.env` и моделью `OPENAI_MODEL` (локальный stub/fallback достаточен для демо);
  - `npm run bots` в этой сессии не запускался;
  - ориентация моделей машин по направлению движения.
- Чанк мира около 1,1 МБ (gzip около 300 КБ): загружается отдельно от 2D-страниц.

## Ограничения
- Вход демонстрационный, без паролей.
- Создание команды по коду приглашения (P1) не сделано.
- Сессии и состояние хранятся в одном файле SQLite. Это прототип, а не продакшен.
